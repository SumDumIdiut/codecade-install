# codecade-install

One-command installer for the [codecade.co.za](https://codecade.co.za) self-hosted stack: temutalk, git-forge, the `tag` game's relay, a recharge mod hub, and a small landing portal tying them all together behind one Cloudflare Tunnel.

## Quick start

```bash
curl -fsSL https://raw.githubusercontent.com/SumDumIdiut/codecade-install/main/install.sh -o install.sh
bash install.sh
```

First run clones/updates each app as a sibling directory, installs everything (portable Node.js, no system install needed), and drops you into a TUI to start/stop services and manage the tunnel.

```bash
bash install.sh                # first run: clone, install, setup, then TUI
bash install.sh start all      # non-interactive start
bash install.sh status         # JSON status snapshot
bash install.sh bundle <dest>  # copy everything to a USB drive for offline use
```

Safe to run repeatedly — every step is idempotent. Never run this with `sudo`.

## What it manages

| Service | Path prefix | Source |
|---|---|---|
| TemuTalk | `/temutalk` | own repo |
| Forge | `/forge` | own repo |
| Tag relay | `/tag` | `tag` repo's `relay-server/` |
| Recharge Hub | `/recharge` | own repo |
| Portal | `/` | generated by this script |

All services run behind one Cloudflare Tunnel pointed at `codecade.co.za`.
